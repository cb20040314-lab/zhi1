一次完整演示的请求时序
①客户端 POST /api/session/start → 拿到 session_id（此后三方所有请求都带它）
②客户端 初始化 video 元素 → 调 Capture.startMonitoring(video, sid) 交给采集
③采集 每 1~2 秒 POST /api/focus 上传人脸特征（表情/朝向/眼睛/质量）
④采集 用户按住说话 → POST /api/turn 上传音频 → 返回 transcript / reply / audio_url
⑤客户端 播放 audio_url，重复 ③④ 共 3~5 轮
⑥客户端 POST /api/session/end → 后端生成画像 → GET /api/report/{id} → 家长页显示专注度曲线+建议
对接口诀：客户端管"会话开始/结束+看报告"，采集管"音频/特征上传"，大数据只管中间处理。 只要 session_id 一致、字段枚举不越界、音频 <15MB，就能串起来。详细字段见 docs/data-contract.md。
