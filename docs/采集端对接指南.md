# 采集端对接指南（真实面部特征 → 后端接口）

> 适用对象：负责"采集"的同学（树莓派 + 摄像头）。
> 验证台里的"发送 20 条特征"是**模拟数据**，真实项目要把下面这套采集逻辑跑在树莓派上。
> 接口唯一依据：`docs/data-contract.md`（v2.0）。

## 1. 你要对接的接口

后端只收**一条一条**的特征事件，接口：

```
POST http://<后端IP>:8000/api/focus
Content-Type: application/json
```

请求体（6 个字段，全是契约规定的枚举/范围）：

```json
{
  "session_id": "s_3f2a1b9c",
  "timestamp": 1760001000000,
  "face_present": true,
  "expression": "neutral",
  "head_direction": "front",
  "eye_state": "open",
  "quality": 0.86
}
```

| 字段 | 类型 | 取值 | 怎么来 |
|---|---|---|---|
| session_id | string | 会话 ID | 会话开始时接口返回（见第 2 节） |
| timestamp | int | 毫秒时间戳 | `int(time.time()*1000)` |
| face_present | bool | true / false | 摄像头里有没有检测到人脸 |
| expression | string | `neutral/happy/sad/surprised/unknown` | 表情识别模型输出（没有模型就固定 `neutral`） |
| head_direction | string | `front/left/right/unknown` | 按人脸框相对画面中心的水平偏移估 |
| eye_state | string | `open/closed/unknown` | 有脸默认 `open`，高级可检测闭眼 |
| quality | number | 0~1 | 人脸框大小/清晰度打分（人脸大且居中≈1） |

**频率建议**：每 1~2 秒发一条（演示收集 20 条约 30~40 秒）。别每帧发，浪费带宽且报告按时间窗口聚合，高频没意义。

## 2. 对接流程（4 步）

```
① POST /api/session/start          → 拿到 session_id
② 摄像头循环：检测人脸 → 算特征 → POST /api/focus × N
③ POST /api/session/end            → 后端生成画像报告
④ GET  /api/report/<session_id>    → 拿报告（专注度曲线/参与度）
```

注意：**语音对话（POST /api/turn）由大树莓派上的语音链路负责，采集端只管发特征**，两边共用同一个 session_id 即可，报告会自动合并对话质量 + 专注度。

## 3. 树莓派参考代码（可跑）

依赖：`pip install opencv-python-headless httpx requests`（树莓派无屏幕用 headless 版）

```python
# collector.py — 采集端最小实现（摄像头人脸检测 → 特征 → 上报）
import time
import cv2
import httpx

BASE = "http://192.168.1.100:8000"   # 改成后端(树莓派)的 IP
face_cascade = cv2.CascadeClassifier(
    cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
)

def extract_feature(frame, sess_id, ts):
    """从一帧画面提取特征（Haar 人脸检测 + 简单规则映射）"""
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_cascade.detectMultiScale(gray, 1.1, 5, minSize=(60, 60))
    h, w = gray.shape[:2]

    if len(faces) == 0:
        return {"session_id": sess_id, "timestamp": ts, "face_present": False,
                "expression": "unknown", "head_direction": "unknown",
                "eye_state": "unknown", "quality": 0.0}

    # 取最大的人脸框
    x, y, fw, fh = max(faces, key=lambda f: f[2] * f[3])
    center_dx = (x + fw / 2) - w / 2          # 相对画面中心的水平偏移
    quality = min(1.0, (fw / w) * 2.0)        # 人脸越宽分越高，粗略打分

    if center_dx < -w * 0.1:
        direction = "left"
    elif center_dx > w * 0.1:
        direction = "right"
    else:
        direction = "front"

    # 演示期不做表情/闭眼识别：固定中性、睁眼（采集端可后接模型升级）
    return {"session_id": sess_id, "timestamp": ts, "face_present": True,
            "expression": "neutral", "head_direction": direction,
            "eye_state": "open", "quality": round(quality, 2)}

def main():
    cam = cv2.VideoCapture(0)
    with httpx.Client(timeout=10) as c:
        # ① 开始会话
        sid = c.post(f"{BASE}/api/session/start", json={}).json()["session_id"]
        print("session:", sid)

        # ② 每 1.5 秒采集上报一条
        last = 0.0
        while True:
            ok, frame = cam.read()
            if not ok:
                continue
            now = time.time()
            if now - last < 1.5:
                continue
            last = now
            feat = extract_feature(frame, sid, int(now * 1000))
            r = c.post(f"{BASE}/api/focus", json=feat)
            print(feat["face_present"], feat["head_direction"],
                  feat["quality"], "->", r.status_code, r.json()["received"])

            if r.json()["received"] >= 20:   # 收满 20 条就结束
                break

        # ③④ 结束会话 + 拿报告
        c.post(f"{BASE}/api/session/end", json={"session_id": sid})
        rep = c.get(f"{BASE}/api/report/{sid}").json()
        print("报告:", rep["focus"]["feature_count"], "条特征,",
              "参与度", rep["focus"]["engagement_score"])

    cam.release()

if __name__ == "__main__":
    main()
```

## 4. 联调自测（不接摄像头也能测）

后端跑起来后，终端一条条发（Windows PowerShell / 树莓派 bash 均可）：

```bash
curl -X POST http://127.0.0.1:8000/api/session/start -H "Content-Type: application/json" -d '{}'
curl -X POST http://127.0.0.1:8000/api/focus -H "Content-Type: application/json" -d '{"session_id":"s_xxx","timestamp":1760001000000,"face_present":true,"expression":"neutral","head_direction":"front","eye_state":"open","quality":0.8}'
curl -X POST http://127.0.0.1:8000/api/session/end -H "Content-Type: application/json" -d '{"session_id":"s_xxx"}'
curl http://127.0.0.1:8000/api/report/s_xxx
```

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| focus 返回 404 SESSION_NOT_FOUND | 先 start 拿 session_id，再发 focus |
| focus 返回 400 会话已结束 | 会话 end 后不再收特征，重新 start 一个新会话 |
| 树莓派连不上后端 | 同一局域网，后端启动用 `--host 0.0.0.0`，采集端 BASE 填后端 IP |
| 采集不到脸 | 光照不足/人脸太小，把 `minSize=(60,60)` 调小，或摄像头对着人脸 1 米内 |
| 上报 20 条后报告里 valid_feature_count < 20 | 正常，quality 过低/枚举非法会被画像分析剔除 |
