# 同学本地使用指南（真实 AI 模式）

跟着做，5 分钟跑通，把语音输入进去就能对话。

## 0. 前提

- 电脑装有 Python 3.10 或更高（`python --version` 可查）
- 能用 git（或用 GitHub 网页下载 zip 也可以）

## 1. 获取项目

```powershell
git clone https://github.com/cb20040314-lab/zhi1.git
cd zhi1
```

（没有 git：GitHub 仓库页面 → Code → Download ZIP，解压后进目录）

## 2. 安装依赖（一次性）

```powershell
pip install fastapi uvicorn python-multipart httpx
```

## 3. 配置真实 AI（用共享 key）

在项目根目录新建文件 `.env`，粘贴以下内容（**key 找才宝旦周要**）：

```
MOCK_AI=0
LLM_API_KEY=填你的key
ASR_API_KEY=填你的key
TTS_API_KEY=填你的key
LLM_BASE_URL=https://api.siliconflow.cn/v1
ASR_BASE_URL=https://api.siliconflow.cn/v1
TTS_BASE_URL=https://api.siliconflow.cn/v1
LLM_MODEL=deepseek-ai/DeepSeek-V4.1-Flash
ASR_MODEL=FunAudioLLM/SenseVoiceSmall
TTS_MODEL=FunAudioLLM/CosyVoice2-0.5B
TTS_VOICE=FunAudioLLM/CosyVoice2-0.5B:alex
```

三个 key 填同一个值即可。

## 4. 启动服务

```powershell
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

看到 `Uvicorn running on http://0.0.0.0:8000` 就是成功了，**这个终端窗口别关**。

## 5. 打开验证台

浏览器打开：**http://127.0.0.1:8000/static/verify.html**

## 6. 输入语音，跑通全链路（4 步）

验证台页面从上到下 4 个步骤，依次点：

1. **服务自检**：点「检查服务」→ 显示 `status: ok` 即可
2. **创建会话 + 语音对话**：
   - 点「创建会话」拿到 session_id
   - 点「选择文件」，选项目里的演示语音（在 `app\static\audio\` 下，共 3 段）：
     - `demo_q1_math.wav`（数学提问）
     - `demo_q2_focus.wav`（专注力提问）
     - `demo_q3_science.wav`（光合作用提问）
   - 点「上传并对话」→ 等 15~30 秒（真实 AI 合成语音需要时间，页面有"处理中"提示，别关页面）→ 显示识别文字 + 回答 + 语音可播放
   - 可换另一段语音再传一轮，多轮对话
3. **模拟专注度特征**：点「发送 20 条特征」→ 进度走完
4. **结束会话 + 报告**：点「结束会话并生成画像」→ 自动显示报告（回合数 / 理由深度 / 参与度 / 专注度曲线）

跑完这 4 步 = 全链路验证通过（语音识别 → AI 回答 → 语音合成 → 专注度画像）。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 启动报 `address already in use` | 8000 端口被占，改端口：命令末尾 `--port 8001`，页面地址也改成 8001 |
| 点「上传并对话」等很久 | 正常，真实 AI 一轮约 15~30 秒，耐心等"处理中"提示结束 |
| 偶发报"ASR/TTS 请求失败 HTTP 500" | 已内置自动重试，再失败就等 1~2 分钟重试一次（服务商高峰抖动） |
| 不想用真实 AI 了 | 把 `.env` 里 `MOCK_AI=0` 改成 `1`，重启即可（不耗额度） |
